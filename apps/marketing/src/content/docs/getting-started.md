# Getting Started with Kortix

Welcome to Kortix! This guide will help you set up your account and start building with AI.

## Prerequisites

- A Kortix account (sign up at kortix.ai)
- A Git repository to connect

## Step 1: Create Your Account

1. Go to [kortix.ai/auth/signup](https://kortix.ai/auth/signup)
2. Sign up with your email or GitHub
3. Verify your email address

## Step 2: Connect Your Repository

1. Navigate to Settings > Repositories
2. Click "Connect Repository"
3. Select your Git provider (GitHub, GitLab, Bitbucket)
4. Authorize Kortix to access your repositories

## Step 3: Start Building

1. Open your connected project
2. Use the AI assistant to describe what you want to build
3. Review and apply the generated code
